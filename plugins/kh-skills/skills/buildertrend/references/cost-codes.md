# KH cost codes (NAHB standard)

The NAHB Standard Homebuilder Cost Codes — the same list Buildertrend ships
as its NAHB template. Use these codes on every estimate line, PO, budget row,
and labor entry so everything reconciles. Seed a new job's `budget.md` with
the codes the job actually uses (don't paste all of them).

Divisions follow the order of construction. 4-digit codes; keep to one level
(NAHB and Buildertrend both advise against sub-code hierarchies).

## Variance reasons

When a budget line goes over, record why using NAHB's standard variance
reasons: **estimating error · plan change · customer change · weather ·
subcontractor error · price increase · theft/vandalism · other**. Track these
in the budget's notes column — patterns across jobs are what improve the next
estimate.

Canonical machine-readable source (for a full expanded list):
